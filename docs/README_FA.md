## معرفی نرم‌افزار

نرم‌افزار **بهینه‌ساز لایه‌چینی کامپوزیت** یک برنامه کاربردی دسکتاپ حرفه‌ای برای بهینه‌سازی توالی لایه‌چینی کامپوزیت با استفاده از **الگوریتم ژنتیک** است.

### ویژگی‌های اصلی:

- ✅ بهینه‌سازی با الگوریتم ژنتیک کدگذاری دودویی
- ✅ اعمال محدودیت تقارن در لایه‌چینی
- ✅ نمودار زنده تابع برازش در هر نسل
- ✅ ویرایشگر اکسل‌مانند برای ویرایش لایه‌ها
- ✅ تحلیل تئوری لایه کلاسیک (CLT)
- ✅ ۱۲ ورودی کامل: ۳ کرنش نرمال، ۳ کرنش خمشی، ۳ نیرو و ۳ ممان

## رابط کاربری

پنجره اصلی برنامه با ابعاد **1024×800** پیکسل طراحی شده و شامل دو تب اصلی است:

### تب ۱: بهینه‌سازی و نظارت (🎯 Optimization & Monitoring)
این تب شامل:
- پنل تنظیمات الگوریتم ژنتیک (سمت چپ)
- نمودار زنده تابع برازش (سمت راست - بالا)
- جدول تاریخچه نتایج و جدول لایه‌چینی بهینه (سمت راست - پایین)

### تب ۲: ویرایشگر لایه‌چینی (📋 Layup Editor)
این تب شامل:
- جدول ویرایش لایه‌ها
- پنل خلاصه لایه‌چینی
- دکمه‌های افزودن/حذف لایه

## تنظیمات الگوریتم ژنتیک

### پارامترهای الگوریتم (Algorithm Parameters):

| پارامتر | توضیح | مقدار پیش‌فرض |
|---------|-------|---------------|
| Population Size | تعداد افراد در هر نسل | 200 |
| Generations | حداکثر تعداد نسل‌ها | 300 |
| Crossover Rate | احتمال تقاطع بین والدین | 0.9 |
| Mutation Rate | احتمال جهش هر بیت | 0.08 |
| Elitism Count | تعداد بهترین‌ها که حفظ می‌شوند | 2 |
| Selection Method | روش انتخاب (tournament/roulette/rank) | tournament |
| Tournament Size | اندازه تورنمنت | 3 |

### محدودیت‌های کامپوزیت (Composite Constraints):

| محدودیت | توضیح |
|---------|-------|
| Max Thickness | حداکثر ضخامت مجاز لمینیت (میلی‌متر) |
| Symmetry Required | اعمال تقارن در لایه‌چینی |
| Balanced Required | اعمال توازن (+θ/-θ) |

## ورودی‌های بهینه‌سازی

برنامه شامل **۱۲ ورودی** برای بهینه‌سازی است:

### کرنش‌های هدف - نرمال (Target Strains - Normal):

| پارامتر | توضیح | واحد |
|---------|-------|------|
| εx | کرنش در جهت x | - |
| εy | کرنش در جهت y | - |
| γxy | کرنش برشی | - |

### کرنش‌های هدف - خمشی (Target Strains - Curvature):

| پارامتر | توضیح | واحد |
|---------|-------|------|
| κx | انحنا در جهت x | 1/m |
| κy | انحنا در جهت y | 1/m |
| κxy | پیچش | 1/m |

### نیروهای اعمالی (Applied Forces):

| پارامتر | توضیح | واحد |
|---------|-------|------|
| Nx | نیروی نرمال در جهت x | N/m |
| Ny | نیروی نرمال در جهت y | N/m |
| Nxy | نیروی برشی | N/m |

### ممان‌های اعمالی (Applied Moments):

| پارامتر | توضیح | واحد |
|---------|-------|------|
| Mx | ممان خمشی حول محور y | N·m/m |
| My | ممان خمشی حول محور x | N·m/m |
| Mxy | ممان پیچشی | N·m/m |

## ویرایشگر لایه‌چینی

ویرایشگر لایه‌چینی امکان تعریف و ویرایش لایه‌های کامپوزیت را فراهم می‌کند.

### ستون‌های جدول لایه‌ها:

| ستون | توضیح |
|------|-------|
| Ply # | شماره لایه |
| Material | نام ماده |
| Angle (°) | زاویه الیاف (درجه) |
| Thickness (m) | ضخامت لایه (متر) |
| E₁ (Pa) | مدول الاستیسیته طولی |
| E₂ (Pa) | مدول الاستیسیته عرضی |
| G₁₂ (Pa) | مدول برشی |
| ν₁₂ | نسبت پواسون |

### مواد موجود در پایگاه داده:

| ماده | توضیح |
|------|-------|
| T300/5208 | کربن/اپوکسی (درجه هوافضا) |
| AS4/3501-6 | کربن/اپوکسی (عملکرد بالا) |
| IM7/8552 | کربن/اپوکسی (مدول متوسط) |
| S-Glass/Epoxy | شیشه/اپوکسی (استحکام بالا) |
| E-Glass/Epoxy | شیشه/اپوکسی (کاربرد عمومی) |
| Kevlar-49/Epoxy | آرامید/اپوکسی (مقاوم در برابر ضربه) |

## نتایج بهینه‌سازی

### نمودار تابع برازش (Live Fitness Plot):
- خط آبی ممتد: بهترین مقدار برازش در هر نسل
- خط سبز خط‌چین: میانگین مقدار برازش در هر نسل

### جدول تاریخچه نتایج (Results History):
این جدول شامل:
- شماره نسل
- بهترین مقدار برازش
- میانگین مقدار برازش
- بهترین زوایا
- ضخامت کل

### جدول لایه‌چینی بهینه (Optimum Layup):
این جدول در سمت راست جدول تاریخچه قرار دارد و شامل:

| ستون | توضیح |
|------|-------|
| Layer Index | شماره لایه (از ۱ تا تعداد لایه‌ها) |
| Optimum Angle (°) | زاویه بهینه برای این لایه |

## نکات مهندسی کامپوزیت

### تقارن (Symmetry):
لمینیت متقارن، لایه‌هایی دارد که حول صفحه میانی آینه شده‌اند. این امر ماتریس B (سختی کوپلینگ) را حذف می‌کند و از تاب‌برداشتن در هنگام پخت جلوگیری می‌کند.

### توازن (Balance):
لمینیت متوازن تعداد مساوی لایه‌های +θ و -θ دارد که کوپلینگ کشش-برش را حذف می‌کند (A16 = A26 = 0).

### زوایای گسسته:
الگوریتم از مجموعه زوایای گسسته استفاده می‌کند:
- 0°, 45°, -45°, 90°

### الگوریتم ژنتیک:
- **کدگذاری دودویی**: هر زاویه با ۲ بیت کدگذاری می‌شود
- **انتخاب تورنمنت**: انتخاب بهترین از بین چند فرد تصادفی
- **تقاطع تک‌نقطه‌ای**: تبادل ژن‌ها بین والدین
- **جهش بیتی**: تغییر تصادفی بیت‌ها

## نتیجه‌گیری

این نرم‌افزار ابزاری قدرتمند برای مهندسان کامپوزیت است که امکان بهینه‌سازی سریع و دقیق لایه‌چینی کامپوزیت را با استفاده از الگوریتم ژنتیک فراهم می‌کند. با رابط کاربری ساده و امکانات گسترده، کاربران می‌توانند:

1. لایه‌چینی خود را تعریف کنند
2. پارامترهای الگوریتم را تنظیم کنند
3. ورودی‌های کرنش، نیرو و ممان را وارد کنند
4. بهینه‌سازی را اجرا کنند
5. نتایج و لایه‌چینی بهینه را مشاهده کنند
